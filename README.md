# Md. Parvez — Personal Research Portfolio

A responsive, static academic portfolio website for Md. Parvez.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository for the website (or use an existing repository).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Content note
The website uses information supplied in Md. Parvez's CV and previously shared profile details. No phone number or residential address is published. Review publication status, dates, links, and all text before making the site public.
